# EduGenie – Google Gemini Powered Educational Assistant

## Abstract
EduGenie is a web-based educational assistant using Google Gemini to provide students with interactive learning support.

## Objectives
- Provide quick educational assistance.
- Explain difficult topics simply.
- Support self-learning.
- Demonstrate generative AI API integration.

## Technologies
Python, Flask, HTML, CSS, JavaScript and Google Gemini API.

## Modules
1. User Interface
2. Question Processing
3. Gemini API Integration
4. Response Display

## Future Enhancements
Quiz generation, login, chat history, voice input and progress tracking.

## Conclusion
EduGenie demonstrates the integration of generative AI into an educational web application.
